# Tables

`manuscript/` contains machine-readable CSV exports of Tables 1-6 from the
latest checked manuscript.  Tables 1-2 are included here even though they are
conceptual rather than benchmark-derived.

`recomputed/` contains the outputs of `scripts/analyze_v1_3.py` for Tables 3-6
and K-sensitivity.  `analysis_metadata.json` records input checksums, run-count
validation, bootstrap method, replicate count, and the neutral seed used by the
new artifact script.

The manuscript itself is deliberately excluded from the public artifact.
