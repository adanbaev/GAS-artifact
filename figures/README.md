# Figures

- Figures 1-2 include vector PDF, high-resolution PNG, and editable Draw.io
  sources. Their PNG files are public rasterizations of the vector PDFs at
  300 dpi.
- Figures 3-6 include manuscript PDF and high-resolution PNG files.
- `Graphical_Abstract/` contains the revised graphical abstract in PDF and PNG.

Plotting sources for Figures 3-6 and the graphical abstract are in `scripts/`.
The figure scripts intentionally use the approved table medians; run-level
statistics are recomputed separately by `analyze_v1_3.py`.
